# Roadmap do Produto — Selftaught

## Fase 1 — Fundação & MVP Completo (Atual)
- [x] Arquitetura e Modelagem de Dados no Backend (FastAPI + SQLAlchemy + Pydantic).
- [x] Autenticação segura com JWT e hash de senhas.
- [x] CRUD completo de Trilhas de Aprendizagem (*Learning Paths*) e Módulos.
- [x] CRUD completo de Tarefas com prioridades, datas e subtarefas.
- [x] Base de Conhecimento com anotações em Markdown e tags.
- [x] Gestão de Recursos de estudo com rastreamento de revisão.
- [x] Dashboard analítico com métricas, prazos e histórico de atividades.
- [x] Interface moderna em Next.js com suporte a tema claro e escuro.
- [x] Suíte de testes automatizados no backend com Pytest.

---

## Fase 2 — Recursos Avançados de Produtividade (Próximas Versões)
- [ ] **Flashcards & Repetição Espaçada (SRS)**: Algoritmo SuperMemo/SM-2 para revisão de conceitos documentados nas notas.
- [ ] **Modo Foco / Pomodoro Timer integrado**: Cronômetro de sessões de estudo que registra automaticamente o tempo real nas tarefas.
- [ ] **Visualização em Grafo de Conhecimento**: Grafo interativo relacionando notas, tags e trilhas (estilo Obsidian).
- [ ] **Importação e Exportação**: Backup completo em JSON/ZIP e importação de notas do Notion/Markdown.

---

## Fase 3 — Assistência Inteligente Opcional (Opt-in)
- [ ] **Assistente de Estudos Local / API**: Sugestão de quebra de tópicos em módulos de aprendizagem via LLM.
- [ ] **Geração Automática de Quizzes**: Testes rápidos criados a partir do conteúdo das anotações em Markdown.
